# Live Wallpapers – Premium Landingpage V5 (Classic Seasonal Experience)

Eine eigenständige, responsive, interaktive Website mit dem originalen ArtIsFantasy-Schloss-Icon als **Classic-Standarddesign**. **Kein statischer Screenshot als Oberfläche.**

## Neu
- Classic startet standardmäßig mit Schloss + Mondsichel in Violett, Blau und Gold.
- 7 Themes: Classic, Halloween, Autumn, Winter, Spring, Summer, Christmas.
- Alle 7 Buttons ändern Website-Hintergrund, zentrales Schloss, Header-Logo, Footer-Logo, Akzente, Glow und Partikel.
- Letzte manuell gewählte Saison wird lokal unter `artisfantasy-season-v5` gespeichert; bestehende `v4`-Auswahl wird absichtlich nicht übernommen, damit Classic beim ersten V5-Besuch aktiv ist.
- `?season=winter` etc. für direkte Links zu einem Theme, `?lang=en` für Englisch.
- 7 DE + 7 EN Screenshots aus der vorherigen Version, jeweils **1080 × 1920 Pixel** (für die Website als hochwertige WebP optimiert). Ohne Verzerrung und ohne Beschnitt. Klick öffnet die Vollbildvorschau.
- Original-Katalogzahlen und Bereiche: 790 Wallpaper, 27 Live-Wallpaper, 78 Kategorien, 27 Kollektionen, Premium/Credits, ArtIsFantasy-Links, FAQ.
- Datenschutz, Impressum, Konto-/Datenlöschseite weiterhin vorhanden und vor Release auf reale Angaben zu prüfen.

## Lokal starten

Datei `index.html` öffnen, oder empfohlen im entpackten Ordner:

```bash
python -m http.server 8000
```

Dann http://localhost:8000 öffnen.

## GitHub Pages

Entpacken und den **Inhalt** des Ordners (index.html, assets/, Datenschutzerklärung usw.) in das Repository hochladen. GitHub Pages auf `main` → `/ (root)` aktivieren.
